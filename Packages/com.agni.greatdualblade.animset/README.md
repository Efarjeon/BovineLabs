# Great Dual Blade Animset

Unity UPM package for the Great Dual Blade animation set.

## Contents

- Humanoid FBX animation clips
- In-place humanoid FBX animation clips
- Animator controllers
- Demo prefab/material/mesh
- Preview scene
- Original animation asset description PDF

## Requirements

- Unity 6000.0 or newer recommended
- No custom runtime scripts required

## Install from GitHub

Unity Package Manager → `+` → **Add package from git URL...**

```text
https://github.com/SadmanShafin/greatdualblade-animset-unity-package.git
```

Or pin the release tag:

```text
https://github.com/SadmanShafin/greatdualblade-animset-unity-package.git#v1.0.0
```

## Usage

After import, open **Packages/Great Dual Blade Animset** and use the FBX clips, animator controllers, prefab, or preview scene in your project.
